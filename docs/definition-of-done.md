# Definition of Done (DoD) — XP Meeting Kata

Une carte ne passe dans **Done** que lorsque tous les critères *applicables* suivants sont vérifiés.

- [ ] Les critères d'acceptation de la fonctionnalité sont explicités et vérifiés.
- [ ] Les tests automatisés sont présents et passent localement.
- [ ] L'intégration continue sur la branche concernée est verte (preuve URL + date).
- [ ] Le code a été relu par une deuxième personne (ou en pairing réellement documenté).
- [ ] Le refactoring nécessaire a été effectué sans modifier le comportement attendu.
- [ ] Le changement est petit et le commit / la pull request est identifiable.
- [ ] Les éventuelles dettes techniques sont enregistrées et priorisées.
- [ ] La documentation utile est actualisée.

**Pour une carte explicitement TDD :** conserver une preuve de RED, GREEN et REFACTOR (commits, captures ou logs). Ne jamais cocher une case sans preuve.

**Note importante :** cette DoD est un accord à adopter et à appliquer par l'équipe. Sa présence dans un fichier ne constitue pas, à elle seule, une preuve de conformité des cartes existantes.
